# 매니저 동행 가이드 현재 위치 확인 구현 기록

## 목적

내부 테스트에서 요청한 “카카오맵 연결 후 현재 자신의 위치 확인”을 매니저 동행 가이드의 상봉 단계에 추가한다.

## 적용 범위

- `MEETING_CONFIRMATION` 단계에서만 `내 현재 위치 확인하기` 버튼을 노출한다.
- 버튼을 누른 시점에만 전경 위치 권한을 확인하고 기기의 현재 위치를 한 번 읽는다.
- 확인한 좌표는 기존 앱 내부 카카오 지도에 마커로 표시하고 해당 위치로 지도를 이동한다.
- 권한 거부, 위치 서비스 꺼짐, 시간 초과, 위치 확인 실패를 각각 안내한다.

## 데이터 경계

이 기능은 화면 표시용 위치 조회다. 좌표를 Core API, PostgreSQL, Firebase, 채팅, 로그에 저장하거나 전송하지 않는다. 기존 위치 공유·실시간 위치 공유 기능과도 연결하지 않는다.

## 선택 이유와 대안

외부 카카오맵 앱으로 이동하는 방식도 가능하지만, 현재 앱에는 이미 카카오 지도 SDK와 상봉 단계 지도 카드가 있다. 따라서 앱을 벗어나지 않고 필요한 시점에 한 번만 확인하는 방식을 선택했다. 지속 추적은 배터리·개인정보·운영 책임 범위가 커져 이번 MVP 범위에서 제외했다.

## 검증 항목

- 상봉 단계에서만 현재 위치 버튼이 표시되는지 확인한다.
- 권한이 없을 때 권한 요청 후 위치 표시가 이어지는지 확인한다.
- 권한 거부 및 위치 서비스 꺼짐 안내를 확인한다.
- 현재 위치를 표시해도 서버 세션 데이터가 바뀌지 않는지 확인한다.

## 후속 검증 기록

- PR #430은 9월 20일 병합됐다. API 24~29 위치 리스너 필수 콜백과 provider 상태 변경 회귀 테스트도 포함한다.
- [PR #410의 9월 22일 승인 리뷰](https://github.com/bodeul110/bodeul-platform/pull/410#pullrequestreview-5279057218)에서 Galaxy S24(Android 16), 실제 DEV 로그인·Core API의 병원·약국 표식, 현재 위치, 지도 이동·복귀·앱 재시작을 확인했다. 위치 공유·DB 위치 저장 없이 검사했고 임시 데이터 정리와 위치 권한 회수도 기록했다.
- 9월 24일에는 위 증적과 코드를 대조했으며 새 실기기 검증은 하지 않았다. 권한 거부·위치 서비스 OFF·시간 초과의 실제 화면 검증은 해당 성공 기록만으로 통과 처리하지 않는다. #424에서 구현 완료와 남은 확인을 구분한다.
