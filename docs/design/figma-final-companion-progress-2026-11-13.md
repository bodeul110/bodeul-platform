# 피그마 완성본 동행 진행·단계별 입력

기준: 2026-11-13, `dev`의 `04daefa7`.

PR 준비 확인: 2026-11-15. 최신 `dev`도 같은 커밋이며, 대상 브랜치는 `dev`다. 아래 계측 결과는 11월 13일 검증 기록이다.

## 작업 목적과 판단

- 작업 목적: 완성본의 동행 타임라인과 단계 입력을 반영하면서 실제 저장·인가·동행 종료 기능을 유지한다.
- 선택한 방식: 매니저의 기존 Coordinator·ViewModel·Repository와 입력 Binder를 재사용하고, 서버 원본 단계를 보존한 9개 표시 그룹과 목록/입력 이동을 추가한다.
- 대안: 서버의 13개 단계를 9개로 즉시 교체하거나 새 저장 경로로 화면을 다시 구현하는 방식을 검토했다.
- 선택 이유: 현재 진행 중인 세션과 구형 7단계의 호환성을 유지해야 한다. 표현 계층에서 묶으면 진료 요약·처방 자료·복약 확인 등 필수 작업을 생략하지 않고 화면을 전환할 수 있다.
- 리스크: 한 표시 그룹에 여러 저장 단계가 대응한다. 현재 단계만 변경 가능하게 하고, 미지원 단계·오류·계정/세션 교체 시 이전 입력을 활성화하지 않는 검증이 필요하다.

## 원본과 범위

- [완성본 동행 진행](https://www.figma.com/design/fqwi44prjEgVFZhaM6LuzS?node-id=1-10211)

- 실제 예약·가이드·세션 값만 표시한다. 시안의 환자 정보·주소·사진·거리·측정 시각·진료 내용은 기본값으로 복제하지 않는다.
- 스캔/OCR·녹음·자동 분석·서버의 새 필드·영상 자산 배포는 이번 UI 작업에서 활성화하지 않는다.
- 의존성·DB·API·운영 설정을 변경하지 않는다. PR 게시와 병합·배포는 별도다.

## 검증 계획

1. 현재·완료·잠금 상태와 13단계/구형 7단계 대응을 단위 테스트한다.
2. 목록/입력 왕복, 입력 오류·저장·재생성·중복 제출·종료/리포트 재시도를 에뮬레이터에서 확인한다.
3. 360/375/412dp와 큰 글꼴에서 입력·하단 버튼·시스템 영역 겹침을 확인한다.
4. `assembleDebug`, 단위 테스트, Android 테스트 APK, Release App Check, 환경 분리 검사와 변경 파일 lint를 확인한다.

`ManagerGuideFinalBinder`는 목록/입력 표시만 담당한다. 단계 전환과 저장은 기존 Activity·ViewModel·입력 Binder·Repository 경로를 호출한다. 진료 기록+요약은 표시 6단계, 약국 이동+처방+복약은 표시 8단계이며, 일지는 9단계 밖의 최종 확인 버튼에서 연다. 구형 가이드에 없는 기초 측정·문진 단계를 임의로 생성하지 않는다.

입력 화면에서 뒤로 가면 목록으로 돌아가며 작성 중인 뷰와 초안을 유지한다. 목록에서 다시 뒤로 갈 때 기존 이탈 확인을 적용한다. 저장 중에는 목록의 재진입 버튼도 잠그며, 채팅 진입은 목록과 만남 화면에 유지했다. 완료 카드의 펼침은 단계 안내 확인이며 저장된 과거 의료 기록 조회 기능으로 표시하지 않는다.

### 남은 범위

- 실제 기기·로그인 계정·Core API·첨부 저장소 왕복은 이번에 실행하지 않았다. 검증은 서버 부작용을 차단한 Debug 저장소 미리보기이며 지도 역시 로컬 대체 표시다. 실제 카카오 지도 초기화·현재 위치·외부 길찾기와 서버 저장 성공까지 검증했다고 보지 않는다.
- 복귀 장소의 지도 좌표 계약이 없어 병원 좌표를 복귀 지도처럼 재사용하지 않는다. 환자 최종 상태 3항목·소지품 확인·보호자 알림의 신규 저장 필드는 추가하지 않았다. 최종 확인 진입은 기존 동행 일지/리포트 제출 경로를 유지한다.
- 진료 요약의 AI 분석·녹음 길이·건강 점수, 녹음/STT·OCR·영상 기능은 활성화하지 않았다. 기존 수동 기록과 파일 선택을 보존하며 미연동 기능을 성공 상태로 표시하지 않는다.
- 환자·보호자 읽기 전용 진행 화면, 별도 최종 리포트 화면과 전체 Figma 적용은 후속 범위다.
- 관리자 웹·Core API·DB·Firebase 규칙·의존성·운영 배포 변경은 없다. 화면 변경을 `dev` 대상 PR로 요청하며, 병합·배포는 별도다.
