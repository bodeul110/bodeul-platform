# 메모·복약 확인 가독성 검증

- 관련 이슈: [#447](https://github.com/bodeul110/bodeul-platform/issues/447)
- 기준: `dev`의 `9de3d06`, 최신 Notion MVP와 내부 테스트의 가독성 피드백

## 구현한 내용

메모 입력에만 전용 본문·힌트·표면 색상 상태를 적용했다. 빠른 메모, 예약 특이사항, 이동·보호자 전달, 진료 요약, 약국·복약 메모와 동행 일지의 다중 행 입력 14개가 대상이다. Material 입력칸이 비활성 상태에서 테마 기본 배경을 상속하지 않도록 배경도 상태 색상으로 지정했다.

종료 전 메모 모아보기의 빈 메모 안내 색을 진하게 하고, C11의 기존 복약 정보 제목·수동 확인 안내·처방 라벨 대비를 보정했다. 제목은 `복약 수령 및 안내 확인`으로 바꾸어 수령과 약사의 안내 여부를 사람이 확인하는 기능임을 명확히 했다. 자동 판독·복약 적합성 판단은 추가하지 않았다.

## 확인

| 검사 | 결과 |
| --- | --- |
| 수정 전 대비 재현 | 기존 메모 힌트 약 3.74:1, C11 작은 제목 약 4.05:1로 4.5:1 검사 실패 |
| 비활성 상태 | 본문 색만 보정할 때 테마 배경 상속으로 약 2.91:1이 되어 배경 상태 색상도 보정 |
| 빌드 | `assembleDebug assembleDebugAndroidTest` 성공 |
| 단위 테스트 | `testDebugUnitTest` 304건, 실패·오류 0건 |
| 환경 경계 | `verifyReleaseAppCheckClasspath`, `node tools/android/check-environment-boundary.mjs` 통과 |
| 기기 UI 테스트 | Galaxy S24 / Android 16에서 로컬 미리보기 패키지 26건 통과 |
| 메모 상태 | 14개 입력칸의 주야간·빈 힌트·포커스·비활성·읽기 전용 대비 4.5:1 이상 |
| 글자 배율 | 320dp 검사 폭, 글자 배율 1·2의 긴 다중 행 메모에서 내용 보존·말줄임·가로 및 세로 잘림 검사 통과 |
| C11 표시 | 등록 정보 없음·합성 기록 있음·처방 이미지 개수·수동 확인 안내 검사 통과 |
| 흐름 회귀 | 복약 메모 저장·재생성·미저장 이탈 방지, 종료 전 메모 표시, C12→C13 이동·300자 제한·일지 제출 미리보기 통과 |

`MemoReadabilityTest`는 기기 전역 테마·글자 설정을 바꾸지 않고 별도 Context에 설정을 적용한다. 가로 폭 검사는 줄 끝의 공백을 제외한 실제 표시 폭을 사용한다. 선택 인수 `readabilityEvidence=true`로 합성 View만 PNG로 남겨 빠른 메모의 야간 표시와 C11 전체 배치도 확인했다. 기기 전체 화면이나 실제 환자 기록은 수집하지 않았다.

## 변경된 범위와 남은 범위

- Android 입력 스타일·문구·메모 표시 색상과 회귀 테스트만 변경했다. 서버·DB·관리자 웹 계약, 의존성, 앱 전체 디자인 토큰은 변경하지 않았다.
- Firebase 설정 없는 Mock/CI 빌드에서 합성 미리보기로 검증했다. 실제 예약의 저장 성공, 서버 인가, OCR 또는 의료 판단, 운영 배포를 검증한 결과가 아니다.
- #422의 실제 신규·재개 세션 단계 비교, #423의 실제 종료·최종 리포트 접근, #448의 실제 예약 이후 하단 탭 전체 경로는 각 이슈의 별도 검증 범위다.
