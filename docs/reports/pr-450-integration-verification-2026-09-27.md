# PR #450 화면 통합 검증

## 범위

- 대상: [#450](https://github.com/bodeul110/bodeul-platform/pull/450)의 예약·보호자 리포트·매니저 가이드 화면과 선행 #444·#445·#446의 연결 구간.
- 코드 기준: 진료 요약 보완 `f34c3a2`, 최신 `dev` 통합 `43d4d22`.
- 기기: Galaxy S24, USB 디버깅. 기기 식별자·계정·인증값은 기록하지 않는다.
- 운영 DB·Firebase·Cloud Run·실제 세션에 쓰지 않는 debug 미리보기와 지연 응답 테스트 저장소를 사용했다.

## 수정

- C07 진료 요약에 기대 세션·단계 검사를 포함하는 저장 경로와 단일 mutation gate를 적용했다. 저장 중 중복 요청·다음 단계·뒤로가기를 차단하고, 늦은 응답이 이미 이동한 화면을 되돌리지 않게 했다.
- 미저장 메모는 ViewModel 메모리에만 유지한다. 재조회·회전 중 초안을 보존하고 다음 단계는 저장 후 진행하며, 이탈할 때는 버리기 확인을 받는다. 프로세스 영구 상태에는 진료 메모를 저장하지 않는다.
- 실패 후 재시도, 메모 전체 비우기, 세션·단계 변경 시 초안 폐기 검사를 추가했다.
- C06→C07, C08→C09, C11→C12 전환 검사를 새 전용 툴바에 맞췄다. 약국 지도 검사는 뷰포트보다 큰 카드 전체가 아니라 지도와 표시 중인 버튼을 각각 스크롤해 확인한다.
- 실기기 캡처에서 확인한 debug 안내와 상태표시줄 겹침을 보완하고 안전 영역 검사에 포함했다.
