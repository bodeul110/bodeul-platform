# 완성본 환자·보호자 홈 검증

기준일: 2026-11-07. 기준 커밋은 #510 병합 후 `dev`의 `1aa8ba6`이며, 이번 변경은 `codex/figma-final-client-home` 작업 브랜치에서 검증했다. 이 문서는 로컬 검증 기록이며 PR의 병합 상태나 배포 완료를 증명하지 않는다.

## 구현한 내용

- [완성본 홈 1:6666](https://www.figma.com/design/fqwi44prjEgVFZhaM6LuzS?node-id=1-6666)의 로고·배너·사진·아이콘과 배치를 반영했다. 필수 텍스트는 #510에서 승인한 대비 보완 원칙을 따른다.
- 예약 위치·날짜·시간과 신규 예약 버튼을 기존 예약 폼에 연결했다. 실제 예약의 일시·장소·진행 단계·완료 후속 정보·보호자 리포트·문의·건강정보·로그아웃 경로를 유지했다.
- 일반 사용자 하단 메뉴를 홈·캘린더·이용내역·채팅·마이로 바꾸고, 캘린더는 기존 본인 예약 조회 결과의 날짜 필터로 연결했다.
- 화면 종료/재조회 후 이전 응답을 무시하고, 캘린더의 선택 날짜와 예약 선택기 진입 여부를 화면 재생성 시 복원한다.

설계 판단, 원본과 다른 데이터 문구, 후속 계약은 [구현 기록](../design/figma-final-client-home-implementation-2026-11-07.md)에 정리했다. 관리자 웹·Core API·DB·운영 설정·의존성 버전은 변경하지 않았다.

## 에뮬레이터 검증

본인 계정·실제 환자/매니저 정보 대신 debug 전용 합성 데이터와 Repository 대체 구현을 사용했다. 미리보기 Activity는 release에 포함하지 않는다. 생성한 두 AVD 인스턴스는 `-read-only -no-snapshot -no-window`로 실행하고 검증 뒤 종료했다.

| 환경 | 검사 | 결과 |
| --- | --- | --- |
| Android 11 / API 30, 360dp, 720×1280, 글꼴 1.0, 3버튼 | 홈·캘린더·공통 메뉴·안전영역 | 23건 통과 |
| Android 11 / API 30, 375dp, 750×1624, 글꼴 1.0, 3버튼 | 동일 검사 | 23건 통과 |
| Android 11 / API 30, 412dp, 824×1830, 글꼴 1.3, 3버튼 | 동일 검사 | 23건 통과 |
| Android 14 / API 34, 375dp, 750×1624, 글꼴 1.0, 제스처 | 동일 검사 | 23건 통과 |
| Android 11 / API 30, 375dp, 글꼴 1.0 | 기존 이동 9건 + 예약 4건 + 로그인 13건 | 26건 통과 |
| Android 14 / API 34, 375dp, 글꼴 1.0 | 동일 회귀 검사 | 26건 통과 |

총 **144회** 통과이며, 같은 테스트를 여러 환경에서 반복한 횟수를 포함한다. 서로 다른 테스트 케이스 144개를 추가했다는 의미는 아니다.

### 확인한 경로

- 예약 없음, 신청/매칭/진행/완료/취소, 보호자 안내와 리포트 진입, 실제 미확인 문의 답변 수.
- 홈 예약 진입 4곳, 기존 날짜 선택기 왕복·재생성 시 자동 재진입 방지, 기존 예약 입력·합성 접수·상세·목록 복귀.
- 5탭의 목적지·선택 상태·뒤로가기, 캘린더와 이용내역 왕복, 기존 채팅·마이 경로.
- 본인 예약만 요청하는 캘린더 조회, 서울 날짜 필터, 날짜 파싱 실패·빈 결과·재시도·선택 날짜 복원.
- 홈 안내 4개 본문, 서비스 소개, 문의·건강정보·로그아웃 진입.
- 인증 실패, 조회 오류/재시도, 화면 이탈 후 지연 응답 무시, 로딩 상태.
- 실제 에뮬레이터 키보드 표시/닫기, 상태바·3버튼·제스처 영역, 글자 잘림·말줄임·터치 영역·재생성 후 메뉴 높이.
- 기존 로그인 입력 오류·로딩·소셜 버튼 연결 등 13개 합성 회귀 경로. 외부 OAuth 로그인 성공 검증은 아니다.

### 캡처에서 보완한 부분

- 개발/Mock 모드 표시가 숨겨질 때 알림 버튼이 왼쪽으로 이동하던 배치를 수정했다.
- 작은 화면에서 캘린더의 오류 재시도 버튼이 고정 메뉴에 가리지 않도록 스크롤의 하단을 메뉴 위에 고정했다.
- 안내의 `자세히 보기`를 원본 `#EDF1F7` 배경·오른쪽 화살표로 맞췄다.
- 스크롤 이벤트와 화면 갱신을 기다린 뒤 실제 화면을 캡처하도록 보완했다.
- API 34 이하에서 decor가 이미 제외한 시스템 바 높이를 다시 더하던 테스트 가정을 수정했다. 실제 버튼이 시스템 바 위에 완전히 노출되는 검사는 유지한다.

화면 이미지는 4개 환경의 상단과 하단, 상태별 화면을 로컬 `.tmp/home-final-captures/`에 남겼다. Figma 원본과 실제 `clean.png`, `empty-bottom.png`, 진행 상태 캡처를 직접 비교했다. 소프트웨어 `View.draw()` 전체 콘텐츠 이미지는 투명 영역·그림자가 실제 화면과 달라 최종 시각 판단 근거로 쓰지 않았다. 캡처와 합성 사용자 데이터는 Git에 추가하지 않는다.

## 정적 검사

```powershell
.\gradlew.bat lintDebug --console=plain
```

전체 lint는 **기존 오류 36건, 경고 250건으로 실패**했다. 오류는 수정하지 않은 보호자 예약 코드의 API 26 `java.time` 사용 35건과 기존 `activity_manager_home.xml`의 include 레이아웃 파라미터 1건이다. 이번 변경 파일에서 새로운 lint 오류는 확인되지 않았다. 구형 리소스 미사용, 원본 알림 배지의 작은 글자 등 경고는 남아 있으므로 lint 전체 통과로 보고하지 않는다. 이를 숨기는 baseline이나 suppress는 추가하지 않았다.

`git diff --check`, 변경 텍스트의 UTF-8 검사와 문서 로컬 링크 63개 존재 확인도 통과했다. API 키·로컬 설정·환경 파일·의존성 변경은 변경 목록에 없다.

## 11월 8일 PR 리뷰 보완 검증

[PR #511의 대비 지적](https://github.com/bodeul110/bodeul-platform/pull/511#discussion_r4501794317)을 `4c057a2`의 앱 코드와 새 계측 테스트로 재현했다. Android 11 / API 30, 375dp에서 안내 카드와 서비스 소개의 실제 확인 버튼은 모두 **2.78395:1**이었고, 두 테스트가 4.5:1 기준에서 실패했다.

두 진입점의 `AlertDialog.Builder`를 `MaterialAlertDialogBuilder`로 바꿔 #510에서 적용한 고대비 버튼 테마를 사용한다. 테마·브랜드색·의존성·인증 및 예약 로직은 변경하지 않았다.

`ClientHomeFigmaPreviewTest`에 회귀 테스트 2건을 추가했다. 각각 환자와 보호자 화면에서 실제 대화상자를 열고 확인 버튼의 현재 글자색과 대화상자 `colorSurface`를 기준으로 대비 4.5:1 이상, 버튼 전체 노출·글자 잘림 없음, 클릭 후 닫힘·홈 중복 조회 없음을 검사한다. 화면 캡처도 함께 확인했다.

## 남은 범위

- 매니저 홈은 다음 구현 단위다. 캘린더 화면 전체, 예약 단계별 화면·두 시각 계약, 실제 콘텐츠·약관 공급 등은 후속 반영 계획을 따른다.
- 실제 기기, 개발 Firebase/Core API/DB 왕복, 실제 로그인 제공자, 관리자 배정부터 동행 종료까지 종단 리허설은 이번에 수행하지 않았다.
- API 24/25 실기기 호환성과 위의 기존 lint 오류는 이 화면 변경의 통과 결과로 해결된 것으로 보지 않는다.
- 운영 배포·DB 변경·사용자 계정 변경은 없으며, 원래 작업 폴더의 사용자 변경은 건드리지 않았다.
